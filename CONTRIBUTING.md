# Contributing to obj-lib

Thank you for considering contributing to `obj-lib`!

## Getting Started

1.  **Fork the repository** to your own GitHub account.
2.  **Clone the project** to your local machine:
    ```bash
    git clone https://github.com/nazmul-devs/obj-lib.git
    cd obj-lib
    ```
3.  **Install dependencies**:
    ```bash
    npm install
    ```

## Development

-   **Build**: Run `npm run build` to compile TypeScript to JavaScript.
-   **Test**: Run `npm test` to run the test suite.

## Pull Requests

1.  Create a new branch for your feature or fix:
    ```bash
    git checkout -b feature/my-new-feature
    ```
2.  Make your changes and ensure tests pass.
3.  Commit your changes following conventional commit messages if possible.
4.  Push to your fork and submit a Pull Request.

## Code of Conduct

Please be respectful and considerate of others when contributing.
